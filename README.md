# Напоминалка в стиле Windows 11

Приложение представляет собой модульный менеджер задач и напоминаний с возможностью автономной работы уведомлений отдельно от графического окна.

## Структура проекта
* **main.py** — Основной графический интерфейс (GUI) на Tkinter. Отвечает за добавление задач, управление фильтрацией и вывод актуальной статистики.
* **scheduler.py** — Невидимая фоновая служба (демон). Запускается автоматически, проверяет системное время каждую минуту, шлет Windows Toast + Pop-up уведомления, даже если главное окно закрыто.
* **database.py** — Слой абстракции данных. Отвечает за SQLite-запросы, создание таблиц, фильтрацию по статусу и расчет статистики для виджета.
* **reminders.db** — Файл базы данных SQLite3 (формируется автоматически при первом старте).

## Кнопки быстрого доступа (Тайм-пресеты)
Для автоматического вычисления даты и времени срабатывания в форме добавления выведены экспресс-кнопки:
* **[Через 1 мин]** — Рассчитывает время на +1 минуту вперед от текущего времени системы.
* **[Через 5 мин]** — Устанавливает таймер на +5 минут.
* **[Через 15 мин]** — Устанавливает таймер на +15 минут.
* **[Через 1 час]** — Выставляет время со смещением ровно на 1 час.

*Кнопка **[Тест уведомления]** мгновенно генерирует задачу на текущую системную минуту для мгновенной валидации работы Windows Toast-уведомлений.*
